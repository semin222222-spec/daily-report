# 로고 슬롯

파일명을 매장 `tag` 와 똑같이 맞춰서 이 폴더에 넣으면 로그인 화면·앱 상단에 자동으로 뜬다.
파일이 없으면 시안과 동일한 타이포 로고(한 글자 배지 / 삐딱 워드마크)로 자동 폴백한다.

| 파일명        | 매장   | 상태 |
| ------------- | ------ | ---- |
| `bbiddak.png`  | 삐딱   | ✅   |
| `woosam.png`  | 우삼집 | ✅   |
| `ssuk.png`    | 쑥고개 | ⬜ 없음 → 타이포 폴백 |

- 권장: 정사각형 또는 가로형 PNG, 배경 투명. 최소 512px.
- 배경이 흰색인 PNG도 괜찮다. 어두운 배경(로그인·사이드바) 위에서는
  자동으로 흰색 라운드 플레이트 안에 올려서 표시한다.
- 매장을 추가하면 `stores.tag` 에 넣은 값과 같은 이름으로 파일을 두면 된다.
